mineworld.

From-scratch neural world models you can drive in the browser — a recursive Minecraft model and a multimodal driving model — plus a real-time image→Minecraft-block-art engine.

Jack Lau github.com/jackulau linkedin.com/in/-jacklau

Everything here runs locally and open-source. The world models generate every frame with a recursive transformer (KV-cached, served over a tiny WebSocket); the block-art engine quantizes to the real Minecraft map palette with OKLab color matching and dithering. Built end-to-end — data, training, serving, and these testers.

01Live neural world models

Each frame is generated by the model from the previous frame + your control — no game engine underneath. The canvas redraws at your screen's refresh rate (display fps), decoupled from how fast the model generates (gen fps), so it's always smooth. Auto-connects to the local servers.

02Image → Minecraft block-art

Drop any image to map it to the 244-color Minecraft map palette (OKLab matching + dithering). Hover the result to identify the exact block; the bill-of-materials lists every block used with a texture-ish icon and count — what you'd need to build it.

    033D voxel builder + replay

    The custom voxel engine extrudes the image into a 3D block build and spins it into an animation — the same volumes the command-block builder emits as a vanilla datapack. Drag to orbit; play/scrub the spin. Real block textures.
