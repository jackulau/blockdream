01 Live models

Live neural world models

02 Block-art

Image → Minecraft block-art

Drop any image to map it to the 244-color Minecraft map palette (OKLab matching + dithering). Hover the result to identify the exact block; the bill-of-materials lists every block used with a texture-ish icon and count · what you'd need to build it.

    03 Voxel builder

    3D voxel builder + replay

    A still image is reconstructed as a real 3D solid · the subject is isolated from its background and inflated by silhouette shape into a centered, double-sided form that reads from every angle, then spun live. An imported GIF or video plays back as a faithful flat block animation instead - the frames are reproduced block-for-block at the source's real timing, not inflated into a blob. The same volumes the command-block builder emits as a vanilla datapack - or save the animation itself as an animated GIF / PNG in pixel-block format. Drag to orbit · hover any block to identify it; raise depth for a fuller build. Real block textures. Drop a model / GIF / video / image straight onto the canvas to import it.

      04 Export

      Load it into Minecraft

      Every downloaded datapack is a ready-to-drop .zip with a HOW_TO_LOAD.txt inside. Quick version:

      Java Edition (1.21+)

      1. Open your world, pause, Open World Folder then the datapacks/ folder (or .minecraft/saves/<world>/datapacks/; a server's is world/datapacks/).
      2. Drop the .zip in there. Do not unzip it.
      3. In game: /reload
      4. Build it: /function blockdream_3d:setup (block-art wall: blockdream:setup)
      5. Play the animation: /function blockdream_3d:start  (:stop to pause)

      Bedrock Edition

      The CLI emits a .mcpack (double-click to import) or a .mcstructure (place with a structure block). Full steps for both editions: docs/load-into-minecraft.md.

      The pack builds at a fixed origin near 0 64 0 (the bundled HOW_TO_LOAD.txt has the exact box) - setup clears that box first, so don't run it inside your base. The same volumes you see in the 3D viewer are what the datapack places, block-for-block.
